Cách hoạt động

Chạy trong 4 bước đơn giản

1
Cài thư viện
pip install -r requirements.txt là đủ. Python 3.8+ trở lên.
2
Cấu hình .env
Điền TELEGRAM_TOKEN và TELEGRAM_CHAT_ID từ BotFather vào file .env.
3
Chạy script
python financial_news_aggregator.py — tự động chạy chu kỳ đầu ngay lập tức.
4
Nhận bản tin
Sau ~90 giây, bản tin đầu tiên xuất hiện trong Telegram. Tiếp tục mỗi 15 phút.

Bắt đầu nhận tin ngay hôm nay

Mã nguồn mở, miễn phí, chạy trên máy tính cá nhân của bạn.

$ pip install -r requirements.txt
$ cp .env.example .env
$ python financial_news_aggregator.py
